# 🚶 안심길 추천 웹서비스

공공데이터와 지도 API를 활용하여 사용자의 이동 경로 주변 안전시설을 분석하고 안전 점수를 제공하는 웹 서비스입니다.

---

## 📌 프로젝트 소개

안심길 추천 웹서비스는 단순한 길찾기 서비스를 넘어 CCTV, 보안등(가로등), 파출소 등의 안전시설 정보를 활용하여 보다 안전한 이동 경로를 제공하는 것을 목표로 개발되었습니다.

사용자는 출발지와 도착지를 입력하면 실제 도로 기반 경로와 함께 주변 안전시설 정보를 확인할 수 있으며, 이를 기반으로 계산된 안전 점수를 제공받을 수 있습니다.

---

## 🎯 개발 배경

최근 범죄 예방과 안전한 귀가에 대한 관심이 높아지면서 단순 최단 경로보다 안전 요소를 고려한 경로 탐색 서비스의 필요성을 느꼈습니다.

본 프로젝트는 공공데이터와 위치 기반 서비스를 결합하여 사용자에게 직관적인 안전 정보를 제공하고, 지도 API 및 외부 Open API 활용 경험을 쌓기 위해 개발되었습니다.

## ⚙ 실행 방법

### 1. 프로젝트 클론

```bash
git clone https://github.com/your-github-id/safe-route-project.git
cd safe-route-project
```

### 2. 패키지 설치

```bash
npm install
```

### 3. 환경변수 설정

프로젝트 루트에 `.env` 파일 생성

```env
KAKAO_REST_API_KEY=YOUR_KAKAO_REST_API_KEY
KAKAO_JS_KEY=YOUR_KAKAO_JAVASCRIPT_KEY
PUBLIC_DATA_KEY=YOUR_PUBLIC_DATA_API_KEY
```

### 4. 서버 실행

```bash
node server.js
```

### 5. 프론트 실행

VSCode Live Server 실행 또는 브라우저에서 `index.html` 실행

## 🧩 문제 해결 경험

### API Key 노출 문제

#### 문제

카카오 API 키가 클라이언트 코드에 노출되는 문제가 발생

#### 해결

Node.js 서버를 구축하여 API 호출을 서버에서 처리하고 `.env` 환경변수로 API Key를 관리

---

### 공공데이터 응답 형식 문제

#### 문제

JSON 응답을 기대했지만 XML 형식으로 반환되는 경우 발생

#### 해결

응답 형식을 검증하고 예외 처리를 추가하여 안정적으로 데이터 처리

---

### 안전시설 분석 정확도 문제

#### 문제

경로와 무관한 시설까지 분석에 포함되어 결과 신뢰도가 낮음

#### 해결

실제 길찾기 경로 좌표를 기준으로 일정 반경 내 시설만 분석하도록 개선
